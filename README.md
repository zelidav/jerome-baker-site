# Jerome Baker site concept

Static concept for the national Jerome Baker site: glass, streetwear, and the Travel Guide.

- `index.html`: home and shop (buying is switched off; "Add to bag" shows a coming-soon note)
- `travel/`: The Jerome Baker Travel Guide. Opens with a "Go full screen" prompt. `F` toggles full screen, `Space` pauses, controls hide when idle. Add `?go` to the URL to skip the prompt (good for kiosks and booth screens).

No build step. Every path is relative, so it runs from GitHub Pages, any static host, or a local folder.
